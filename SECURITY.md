# Reporting problems

For ordinary bugs and questions, use https://github.com/tpfjr/daymark/issues.
Do not attach planner databases, private calendar exports, or credentials.

For suspected vulnerabilities, use GitHub's private reporting form:
https://github.com/tpfjr/daymark/security/advisories/new
Do not post exploit details or private data in public Issues. If the form is not
available, private vulnerability reporting has not yet been enabled; do not post
sensitive details publicly. No private email address is published here.

No public release is supported yet. Unsigned development builds are test candidates,
not a completed public launch. Review RELEASE.md and release-readiness.json.
